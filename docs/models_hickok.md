## Czech HiČKoK Model #czech_hickok_model

Czech HiČKoK Model is distributed under the
[CC BY-NC-SA](https://creativecommons.org/licenses/by-nc-sa/4.0/) licence.
The model is trained using the [RobeCzech model](https://hdl.handle.net/11234/1-3691).

The models require [UDPipe 2](https://ufal.mff.cuni.cz/udpipe/2).

### Download

The latest version 261120 of the Czech HiČKoK model
can be downloaded from the [LINDAT/CLARIN repository](http://hdl.handle.net/11234/TODO).

The model is also available in the [REST service](https://lindat.mff.cuni.cz/services/udpipe/).
